# Spare Parts E-commerce Platform

An e-commerce marketplace for automotive/industrial spare parts, built to handle a 5,000+ SKU catalog with make/model/year fitment search, guest and account checkout, Razorpay-style payments, Shiprocket-based order tracking, and a full admin dashboard — delivered over a 9-week timeline on a ₹25,000 development budget using a Node.js/NestJS + PostgreSQL backend (`/backend`) and a Next.js + Tailwind frontend covering both the customer storefront and admin dashboard (`/frontend`), with UI/UX specs produced by the design track (`/design`).

See [`/docs`](./docs/README.md) for the shared planning artifacts every team builds against: the [project plan](./docs/PROJECT_PLAN.md), [API contract](./docs/API_CONTRACT.md), [data model](./docs/DATA_MODEL.md), [design brief](./docs/DESIGN_BRIEF.md), and [backlog](./docs/BACKLOG.md).
